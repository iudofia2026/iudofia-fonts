Google Fonts (designhub root layout)

These are loaded with next/font/google in designhub/app/layout.tsx, not duplicated as files in this repo. CSS variables: --font-inter, --font-heading, --font-body.

  • Inter npm / Google Fonts --font-inter · default UI sans stack
  • Hammersmith One npm / Google Fonts --font-heading · Tailwind / globals.css fallbacks
  • Space Grotesk npm / Google Fonts --font-body · Tailwind / globals.css fallbacks

System stacks (no files)

Some portfolio and lab components use -apple-system, Segoe UI, Roboto, or generic monospace for UI chrome or SVG text.
